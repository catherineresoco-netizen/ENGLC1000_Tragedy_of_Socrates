# The Paradox of Democracy
Open index.html in a browser. Upload the contents of this folder to a GitHub repository, then Settings > Pages > Deploy from a branch > main / (root) > Save.

Four paintings are bundled as low-resolution crops of the supplied collage. The David painting is loaded from Wikimedia Commons if available; for reliable offline operation download the original public-domain image from https://commons.wikimedia.org/wiki/File:Jacques-Louis_David_-_The_Death_of_Socrates_-_Google_Art_Project.jpg and save it as images/david.jpg. If neither loads, the first room displays Fabre with the correct credit. Replace the other JPEGs with high-resolution credited reproductions using the same filenames. The palette is visually inspired, not pixel-sampled.

Edit index.html for text, style.css for visual design, script.js for scroll and fade behavior. No framework or build step required. The sources dialog includes references and artwork attribution notes; match the textual references to your verified editions before submission.
