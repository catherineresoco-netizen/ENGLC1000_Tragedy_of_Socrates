# The Paradox of Democracy
Open index.html in a browser. Upload it to the root of a GitHub Pages repository.

Five horizontal rooms, arrow buttons, Roman numeral navigation, wheel and touch scrolling. Artwork from the uploaded reference is embedded. Other artwork loads from Wikimedia Commons and requires internet access; if blocked, the artwork label links to the original. David falls back to the embedded Fabre painting. To make the external works offline-ready, download the linked original files and replace their image src attributes with local paths or data URLs.

The Weimar visual is the 1933 Enabling Act document, rather than a photograph. Works Cited links are included; retain your verified library edition details for submission.
